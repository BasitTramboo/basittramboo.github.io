# Basit Tramboo — Portfolio

Personal portfolio site for [Basit Tramboo](https://basit.tramboo.dev), Senior Full Stack Developer at CGI.

Built with React 19 and Vite. Deployed to GitHub Pages with a custom domain.

## Local development

```bash
npm install
npm run dev
```

Visit `http://localhost:5173`.

## Build & preview

```bash
npm run build
npm run preview
```

## Deploy

Pushes to `main` trigger the GitHub Actions workflow in `.github/workflows/deploy.yml`.
